## The one that can kill four trials

Nine encounter modules start with a UTF-8 BOM, added by `a4e2942` (2026-08-25,
the `Location.new(0,0,0,0,0,0)` → `nil` refactor). Lua's own CLI loader skips a
BOM; an embedded loader that hands the file body to `lua_load()` may not. If ESO
does not, `trial/as`, `cr`, `lc` and `oc` fail to register and die at require
time with a single chat line. Byte-level fix, one command:

```sh
python3 review/2026-09-01/checks.py --repo .       # C-01 names all nine files
git am review/2026-09-01/patches/01-fix-strip-utf8-bom.patch
```

Whether ESO tolerates a BOM is the one thing this review could not settle
externally — the fix is free, so it is worth landing before the answer arrives.

## Three findings worth a decision (no patch supplied, on purpose)

1. **`showBossUI` is write-only in all nine trials** (F-06). Nine checkboxes in
   the LAM panel, zero readers. Wire the header in `Trial:onBossesChanged` (the
   boss, the slot and `AlertSink:showHeader` are all already there) or delete the
   setting. A patch here would have to guess which product you want.
2. **Hardmode detection is a guess for 16 of 25 bosses** (F-04, F-22). 7 ×
   `math.huge`, 5 × `100000001`, 4 modules with no field at all — and 42
   `context.isHM` gates in Lylanar/Bahsei/Xalvakka/Taleria branch on it, so a
   wrong boundary silently shows or hides whole mechanics. Patch `04` makes the
   gap visible in chat and adds `/incha hp`; the numbers themselves need one
   in-game session.
3. **`KA` has no Enable checkbox while the other eight trials do** (F-24), and
   `Enable` only takes effect on the next zone change (F-09). Patch `05` fixes
   both.
